# L-ubu.github.io

The hub for all my GitHub Pages sites — one page, one working terminal, every project.

**Live:** https://l-ubu.github.io/

## What it is

A single `index.html` that indexes all my Pages sites:

- A **working terminal** — `help`, `ls`, `ls security`, `open frisk`, `whoami`, with tab-completion and history
- A **card grid** rendered from the same registry — each card glows in its project's accent color
- Category filters: tools, security, gesture, play, misc
- A small "deployed elsewhere" table for the Vercel apps

No build step, no dependencies. Edit the `PROJECTS` array in `index.html` to add a site.
